# daily-book-video

每天推荐一本书的完整闭环 Skill：选题去重 → 文案 → 6 段 AI 视频 → 配音 → 合成 → 字幕 → 质检 → 发布到微信视频号 / 抖音 / 小红书 → 逐平台回查验证 → 更新去重账本。

成功的定义只有一个：**内容出现在平台的内容列表里（LIST_VERIFIED）**，不是接口返回成功、不是上传完成。

## 内容

- [`SKILL.md`](SKILL.md) — 完整流程：生产管线、逐平台发布方法、配乐规则、停止条件、排错表，以及相对原文方法的实测修正。

## 要点

- 每期一本没发过的书，配音稿 300–340 字，成片 50–65 秒（以配音真实时长为准，不注水）。
- 每期最多生成 6 条视频片段，不合格段落用合格片段截帧 Ken Burns 补位。
- 配乐优先用平台自带的选音乐功能；不用时混入可商用纯音乐垫底，绝不提取他人音频、不下载版权录音。
- 视频号发布时声明原创，同时勾选「含 AI 生成内容」。
- 登录失效、验证码、风控时只跳过该平台并报告，不硬闯。

## 来源

源自一篇公开实操文章的方法，经实际生产一期（《活着》三平台首发）后的修正版。
